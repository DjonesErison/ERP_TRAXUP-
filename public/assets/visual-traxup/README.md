# Referências visuais TRAXUP

Esta pasta armazena as pré-criações visuais oficiais usadas como referência para implementação das telas da Central TRAXUP.

- Trial de 7 dias
- Painel administrativo SaaS
- Assistente IA
- Menu ERP / ecossistema

## Convenção

Os arquivos PNG devem ser mantidos nesta pasta e tratados como referência visual de produto. A presença de uma imagem não significa que a funcionalidade esteja implementada no backend.

As telas Angular devem consumir os arquivos por `/assets/visual-traxup/<arquivo>.png` quando necessário.
