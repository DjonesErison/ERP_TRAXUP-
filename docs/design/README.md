# TraxUp — Catálogo Visual

Este diretório reúne as referências visuais aprovadas para implementação da Central Web, PDV, aplicativos e administração SaaS.

## Regras de uso

- As imagens são referências de interface; a aplicação deve ser construída em componentes Angular.
- Somente versões aprovadas devem permanecer neste catálogo.
- Textos, valores, empresas, produtos e datas exibidos são dados demonstrativos.
- Toda implementação deve respeitar multi-tenant, permissões, LGPD e acessibilidade.

## Identidade visual

- Azul royal: estrutura, navegação e ações secundárias.
- Laranja: ação principal e destaques.
- Branco e cinza frio: superfícies e fundos.
- Verde, amarelo e vermelho: estados operacionais.
