# TRAXUP UI-001 — Dashboard do ERP

Protótipo funcional em Angular 19 com Tailwind CSS 4, baseado integralmente na referência visual UI-001 do projeto.

## Funcionalidades

- navegação e seleção de loja;
- busca global e filtro de período;
- acesso às últimas vendas e aos alertas;
- ações de download do PDV e acesso remoto;
- Assistente IA demonstrativo.

Abra `TRAXUP-UI001-Dashboard-Prototipo.html` para validar sem instalar dependências, ou execute `npm install && npm start`.

Os dados são locais e demonstrativos.
