# Protótipo de Clientes — TRAXUP

Protótipo funcional em Angular 19 e Tailwind CSS 4 baseado nas referências oficiais:

- `clientes.webp`: consulta principal;
- `UI-021`: cadastro e edição;
- `UI-022`: visão 360º.

## Executar

```bash
npm install
npm start
```

## Funcionalidades demonstrativas

Busca, filtros, seleção, cadastro em quatro etapas, edição, ativação/desativação, visão 360º e abas de compras, financeiro, CRM e LGPD. Os dados são locais e não acessam API ou banco.
