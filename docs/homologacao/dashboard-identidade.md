# Dashboard — identidade visual e filial ativa

A barra lateral usa a logomarca oficial `assets/Logo.png`. O cabeçalho mostra o CNPJ da filial selecionada, formatado, ou “Não informado” quando ausente. O filtro por período e a atualização permanecem; a busca por pedido foi retirada do dashboard. O painel continua utilizando os dados reais da filial ativa.
