# TRAXUP UI-003 - Produtos

Protótipo funcional em Angular 19 e Tailwind CSS 4, baseado na referência visual UI-003 do repositório ERP_TRAXUP-.

## Executar

```bash
npm install
npm start
```

## Funcionalidades

- pesquisa e filtros combinados;
- indicadores automáticos;
- seleção individual e em lote;
- painel lateral de detalhes;
- cadastro e edição em modal;
- duplicação, exclusão demonstrativa e alteração de situação;
- exportação CSV;
- layout responsivo com grid Tailwind.

Os dados são locais e demonstrativos; nenhuma API de produção é chamada.
