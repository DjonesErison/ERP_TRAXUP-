# TRAXUP UI-011 — PDV Desktop

Protótipo funcional em Angular 19 com Tailwind CSS 4, baseado integralmente na referência visual UI-011 do projeto.

## Funcionalidades

- busca e inclusão demonstrativa de produtos;
- teclado virtual e identificação do consumidor;
- alteração de quantidade e aplicação de desconto;
- consulta de últimas vendas e cancelamentos;
- recebimento com seleção da forma de pagamento;
- acesso às configurações do PDV.

Abra `TRAXUP-UI011-PDV-Desktop-Prototipo.html` para validar sem instalar dependências, ou execute `npm install && npm start`.

Os dados são locais e demonstrativos.
